I built this site to be accessible, fast and honest about what it does. Now the code behind it is a template that anyone can use for their own portfolio and blog. It is called [astro-cat-portfolio](https://github.com/sindurigf/astro-cat-portfolio), and it is free under the MIT licence.

Instead of my face and my words, it comes with cats. The bunny from this site became a cat, and every photo in the template is one of my cats. Honestly, they deserve the fame.

## What you get

- **The design.** The gold slab, the bold type, the pink shadows and the cyan focus ring, in light and dark mode. Every colour is a named token, so you can change the look in one place.
- **A portfolio and a blog.** Home, about, blog with categories and tags, RSS feeds, a talk slideshow, contact, privacy and accessibility pages.
- **The tests.** Automated accessibility checks run on every page in Chromium, Firefox and WebKit, against WCAG 2.2 AA. They cover contrast, keyboard focus, target sizes, reflow at 320 pixels, reduced motion and more.
- **A contact form that respects privacy.** It runs on Cloudflare Workers, and the setup steps keep messages in the EU. If you do not want a form, one setting turns it into a plain email link.
- **Checks that catch mistakes.** The checks fail if a photo still carries location data, if a colour is not a token, or if a link is broken.

## How to use it

1. Open the [repository](https://github.com/sindurigf/astro-cat-portfolio) and select **Use this template**.
2. Put your name, your domain and your profiles in `src/site.config.ts`. That one file is all you need to change to make it yours.
3. Run the tests. They pass on the first run, with no accounts or secrets.
4. Replace the lorem ipsum with your own words, and the cats with your own photos. Or keep the cats. I would understand.

The README has the full steps, including how to deploy.
