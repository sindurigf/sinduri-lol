# Security

Report a vulnerability privately, not in a public issue:

1. GitHub private vulnerability reporting: "Report a vulnerability" on the
   Security tab
   ([new advisory](https://github.com/sindurigf/sinduri-lol/security/advisories/new)).
2. Email <lol@sinduri.lol>.

- The email contact, and what the site runs, is in
  [/.well-known/security.txt](https://sinduri.lol/.well-known/security.txt),
  generated by `src/pages/.well-known/security.txt.ts`.
- Accessibility barriers are not security reports:
  [ACCESSIBILITY.md](ACCESSIBILITY.md#8-reporting-a-barrier).
